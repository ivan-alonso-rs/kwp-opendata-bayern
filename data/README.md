# data/

Local working data. **Contents are git-ignored** (only this README and the
`.gitkeep` files are versioned).

| Folder | Content | Written by |
|---|---|---|
| `raw/` | original downloads, never edited by hand | `scripts/01_download.py` |
| `interim/` | intermediate files (clipped, reprojected) | pipeline steps |
| `processed/` | final layers for maps and validation | pipeline steps |

Everything here can be regenerated by re-running the pipeline.
